# Черновик структуры отчёта

## Введение
Цель работы — разработать веб-приложение AutoBoard для размещения и поиска объявлений о продаже автомобилей с использованием Django и PostgreSQL.

## Требования к системе
Система должна поддерживать регистрацию с подтверждением, личный кабинет, роли пользователей, CRUD объявлений, модерацию, поиск, фильтрацию, избранное, сообщения продавцу, cookie и cache.

## Описание системы
AutoBoard состоит из клиентской части на HTML/CSS/JavaScript и серверной части на Django. Данные хранятся в PostgreSQL.

## Серверная часть
Основные модели: Profile, SellerInfo, CarAd, CarImage, CarTag, Favorite, Message, Review. Серверная логика реализована во views и forms приложения helloapp.

## Клиентская часть
Используются Django-шаблоны, адаптивная CSS-вёрстка и JavaScript для динамического выбора модели автомобиля, AJAX-проверки контактов, избранного и асинхронной статистики.

## Выводы
В результате разработано веб-приложение, соответствующее критериям курсовой работы на оценку «5».
